# 기능 명세서

화면별 기능과 동작 규칙. API 스펙은 [`api.md`](./api.md)를 참고한다.

**상태**: ✅ 동작 · 🟡 화면 완성, 서버 연동만 남음 · ⬜ 미구현

> **모든 데이터는 mock(`src/mocks/`)이다.** 화면은 전부 완성됐고 서버 연동만 남았다.
> 🟡는 프론트가 할 일이 없다는 뜻이고, ⬜만 실제로 남은 작업이다.

---

## 1. 서비스 개요

AI가 학습·습관을 **먼저 챙기고 독촉하는** 앱.

**목표(Goal) = 채팅방.** 목표 하나가 AI와 대화하는 방이고, 거기에 투두·플래너·집중 기록·첨부가 매달린다. 홈의 목표 카드, 기록의 투두, 모아보기가 모두 같은 id의 목표를 다른 각도로 보여준다.

이름은 둘이다. `name`은 채팅방 별명(Buddy), `title`은 목표 이름(UI/UX 디자인 강의 완주).

## 2. 화면 구조

```
/landing  /signin  /signup  /auth/callback/:provider
─────────────────────────── 하단 탭바
/home   /chat   /focus   /record   /my
─────────────────────────── 전체 화면
/chat/:goalId              채팅방
/chat/:goalId/archive      모아보기
/chat/:goalId/settings     목표 설정
/settings                  앱 설정
/settings/history          히스토리(숨긴 채팅방)
```

## 4. 홈 `/home`

### 안 읽은 메시지 미리보기

| 기능      | 상태 | 설명                                        |
| --------- | ---- | ------------------------------------------- |

| 카드 종류 | ✅   | 메시지 / 공지 / 광고                        |

| 기능           | 상태 | 설명                                     |
| -------------- | ---- | ---------------------------------------- |
| 오늘 집중 시간 | ✅   | 집중 탭과 같은 데이터                    |
| 목표 시간      | ✅   | **오늘 플래너의 계획 시간 합계**         |

| 목표 카드      | 🟡   | 목표 이름 + D-day + 진행률. 완주한 목표는 제외 |
| 목표 추가하기  | ✅   | 채팅 탭으로 이동해 개설 팝업             |

### 알림

| 기능         | 상태 | 설명                                                     |

| 알림 종류    | 🟡   | 독촉 / 투두 추가 / 완료 / 밤 11시 미완료 / 플래너 미작성 |

| 일반 채팅 알림 | —  | **만들지 않는다.** 독촉만 대상                           |

## 5. 채팅

### 목록 `/chat`

| 기능      | 상태 | 설명                                                       |
| --------- | ---- | ---------------------------------------------------------- |
| 목표 목록 | 🟡   | 아바타 + 이름 + 최근 메시지 + 시각 + 안 읽음 배지          |
| 정렬·검색 | ✅   | 최근 메시지순(**읽어도 순서 불변**), 검색은 프론트 필터링  |
| 목표 개설 | 🟡   | `+` → 팝업(이름·사진·AI 성격·목표·프롬프트). **이름만 필수** |
| 숨긴 방   | ✅   | 목록에서 제외                                              |

### 채팅방 `/chat/:goalId`

| 기능           | 상태 | 설명                                          |
| -------------- | ---- | --------------------------------------------- |
| 말풍선·날짜 구분선 | ✅ | 내 메시지 오른쪽, AI 왼쪽                     |
| 메시지 전송    | 🟡   | 낙관적 업데이트, 실패 시 "다시 시도"          |
| 과거 메시지    | ✅   | 위로 스크롤하면 커서 페이지네이션으로 이어붙임 |
| 입력창         | ✅   | 1000자 제한                                   |
| 파일 첨부      | 🟡   | **jpg·png·pdf·txt, 10MB**                     |
| 사진 미리보기  | ✅   | 말풍선 썸네일 → 누르면 전체 화면              |
| AI 응답        | 🟡   | 현재 고정 문구                                |
| SSE 스트리밍   | ⬜   | 스펙 확정, **연동 후 구현**                   |
| 파일·사진 저장 | ⬜   | 웹에선 갤러리 저장 불가. **앱 전환 후**       |

### 모아보기 `/chat/:goalId/archive`

| 기능      | 상태 | 설명                                          |
| --------- | ---- | --------------------------------------------- |
| 파일 · 사진 탭 | 🟡 | 연-월로 묶어 표시. 사진은 **썸네일 URL 필요** |
| 진도 탭   | 🟡   | 원형 진도율 + 마일스톤 타임라인               |
| 완료 목표 | ✅   | 완주 축하 화면 + 기간·소요일수                |
| 회고 지표 | ⬜   | 집중 시간·완료한 할 일·가장 열심히 한 달. **서버 집계 필요** |

### 목표 설정 `/chat/:goalId/settings`

| 기능             | 상태 | 설명                                             |
| ---------------- | ---- | ------------------------------------------------ |
| 기본 정보 수정   | 🟡   | 사진·이름(10자)·목표(50자)·프롬프트(500자)       |
| 기한             | 🟡   | 즉시 저장. 홈 D-day에 반영                       |
| 진도             | ⬜   | 읽기 전용. **스키마 확정 후 편집**               |
| 목표별 알림 끄기 | 🟡   | 전역 설정과 별개, 즉시 저장                      |
| 목표 완료 처리   | 🟡   | 확인 팝업 → 완주 기록                            |
| 채팅방 숨기기    | 🟡   | 목록에서만 숨김. 히스토리에서 되돌림             |
| 대화 삭제 · 목표 삭제 | 🟡 | **삭제 시 데이터 처리 정책 미합의**             |
| AI 성격 수정     | ⬜   | 개설할 때만 고를 수 있고 나중에 못 바꾼다        |

| 오늘 집중 요약   | 🟡   | 집중 시간 / 목표 시간                                  |

캘린더 ↔ 텐미닛 플래너를 탭으로 전환.

### 캘린더 · 투두

| 기능        | 상태 | 설명                                                    |
| ----------- | ---- | ------------------------------------------------------- |
| 월 이동·날짜 선택 | ✅ |                                                        |
| 완료 표시   | 🟡   | **완료한 항목 하나가 꽃잎 하나**(최대 4장), 색은 목표별 |
| 날짜별 투두 | 🟡   | **투두는 날짜마다 새로 생성.** 목표별 카드로 좌우 슬라이드 |
| 체크        | 🟡   | AI도 갱신하고 **사용자도 직접 체크**                    |
| 항목 추가   | 🟡   | **카드를 길게 누르면** 추가 팝업. 목표당 하루 10개까지  |
| 항목 수정·삭제 | 🟡 | **내가 추가한 항목만.** AI가 만든 항목은 체크만 되고 대화로 바꾼다 |
| 수정 가능 범위 | ✅ | **오늘, 진행 중인 목표만**                              |

### 텐미닛 플래너

| 기능           | 상태 | 설명                                             |
| -------------- | ---- | ------------------------------------------------ |
| 날짜 이동      | ✅   | **오늘 이후 이동 불가**                          |
| 표             | 🟡   | 1시간 단위, 06:00~24:00(설정에서 변경)           |
| 막대           | ✅   | 계획 / 실제(출처별 색)                           |
| 요약           | ✅   | 계획·달성·미달성 블록 수와 달성률(10분 = 1블록)  |

| 실제 기록 추가 | 🟡   | **빈 시간대를 누르면** 추가 팝업(제목 + 시작·종료)     |
| 실제 기록 수정·삭제 | 🟡 | **막대를 누르면** 수정 팝업, 삭제는 팝업 아래에        |
| 수정 가능 범위 | ✅   | **오늘의 지나간 시간만**                               |

## 10. 공통 규칙

**데이터 상태** — 조회 화면은 로딩(스켈레톤) → 성공 / 실패(다시 시도) / 빈 상태를 갖는다.

**저장 방식**

| 방식              | 쓰는 곳                                              |
| ----------------- | ---------------------------------------------------- |
| 즉시 저장(낙관적) | 설정 토글, 기한, 알림 끄기 — 실패 시 되돌리고 토스트 |
| 명시적 저장       | 프로필, 목표 기본 정보 — 변경이 있을 때만 버튼 활성  |
| 낙관적 추가       | 채팅 메시지 — 먼저 그리고 실패 시 "다시 시도"        |

**시간 표기** — 서버는 **ISO 8601(UTC)만** 주고 프론트가 상대 시간·날짜 형식으로 변환한다(`src/utils/date.ts`). 날짜 파라미터는 사용자 로컬 기준 `YYYY-MM-DD`.

## 11. 남은 작업

**프론트에서 가능**

- 목표 설정에서 AI 성격 수정
- 파일·사진 저장(앱 전환 후가 나음), 약관 링크 연결

**서버 필요**

- API 실제 연동(`src/api/` 9개 파일 전부 mock), SSE 스트리밍
- 연속 달성일, 마이페이지 통계 3종, 목표 회고 지표, 기간별 집중(히트맵)
- 밤 11시 독촉 알림(스케줄러 + 푸시), **알림 실시간 수신 채널**

**앱 전환(Capacitor)**

- 푸시 알림, 집중 중 상주 알림, 알림 권한·기기 토큰 등록

**팀 작업**

- 카카오·구글 클라이언트 ID 발급 (이것만 하면 소셜 로그인 동작)

**결정 필요** — [`api.md` 8장](./api.md#8-결정이-필요한-것)
