# 기능 명세서 (프론트엔드)

nudgely의 화면별 기능과 동작 규칙을 정리한 문서. API 스펙은 [`api.md`](./api.md)를 참고한다.

**상태 표기**: ✅ 동작 · 🟡 화면만(mock) · ⬜ 미구현

> 현재 모든 데이터는 mock(`src/mocks/`)으로 동작한다. 백엔드 연동 시 `src/api/*.ts` 함수 내부만 교체하면 화면 코드는 그대로다.

---

## 1. 서비스 개요

AI가 사용자의 학습·습관을 **먼저 챙기고 독촉하는** 앱.

**핵심 모델: 목표(Goal) = 채팅방.** 사용자가 만든 목표 하나가 곧 AI와 대화하는 채팅방이고, 그 목표에 투두·플래너·집중 기록·첨부가 모두 매달린다.

| 화면     | 그 목표를 어떻게 보여주나 |
| -------- | ------------------------- |
| 채팅     | AI와 대화하는 방          |
| 홈       | 진행 중인 목표 카드       |
| 기록     | 그날의 투두 카드          |
| 모아보기 | 주고받은 파일·사진·진도   |

**이름은 둘로 나뉜다.** `name`은 채팅방 이름(별명, 예: Buddy), `title`은 목표 이름(예: UI/UX 디자인 강의 완주). 홈·기록 카드 제목과 채팅 상세 부제는 `title`을 공유한다.

## 2. 화면 구조

```
/landing                     시작 화면
/signin  /signup             로그인 · 회원가입
─────────────────────────── 하단 탭바 (5개)
/home                        홈
/chat                        채팅 목록
/focus                       집중
/record                      기록
/my                          마이페이지
─────────────────────────── 전체 화면 (탭바 없음)
/chat/:goalId                채팅방
/chat/:goalId/archive        모아보기
/chat/:goalId/settings       목표 설정
/settings                    앱 설정
/settings/history            히스토리(숨긴 채팅방)
```

## 3. 인증

### 3.1 시작 화면 `/landing`

| 기능                        | 상태 | 설명                                                                                    |
| --------------------------- | ---- | --------------------------------------------------------------------------------------- |
| 이메일 회원가입·로그인 이동 | ✅   |                                                                                         |
| 카카오·구글 로그인          | 🟡   | 리다이렉트 → 콜백 → 코드 전달까지 구현. **클라이언트 ID 발급 필요**(없으면 안내 토스트) |

### 3.2 로그인 `/signin`

| 기능                   | 상태 | 설명                                                                        |
| ---------------------- | ---- | --------------------------------------------------------------------------- |
| 이메일·비밀번호 로그인 | 🟡   | 성공 시 토큰 저장 후 홈으로                                                 |
| 입력 검증              | ✅   | 빈 칸이면 버튼 비활성                                                       |
| 실패 안내              | ✅   | "이메일 또는 비밀번호를 다시 확인해주세요" (계정 존재 여부를 드러내지 않음) |
| 비밀번호 찾기          | 🟡   | 팝업에서 이메일 입력 → 재설정 메일 발송                                     |

### 3.3 회원가입 `/signup`

| 기능                        | 상태 | 설명                                    |
| --------------------------- | ---- | --------------------------------------- |
| 닉네임·이메일·비밀번호 가입 | 🟡   | 가입 즉시 로그인 상태가 됨              |
| 닉네임 길이 제한            | ✅   | 10자                                    |
| 비밀번호 규칙               | ✅   | 8자 이상 + 확인 일치. 미달 시 즉시 안내 |
| 이메일 중복 확인            | 🟡   | 제출 시점에 확인                        |

### 3.4 토큰 관리

- 액세스 토큰은 `localStorage`에 저장하고 모든 요청에 `Authorization: Bearer`로 자동 첨부한다.
- **401 응답이면 토큰을 지우고 로그인 화면으로 보낸다.**
- ⬜ 리프레시 토큰·만료 정책 미정.

## 4. 홈 `/home`

### 4.1 안 읽은 메시지 미리보기

| 기능               | 상태 | 설명                                                    |
| ------------------ | ---- | ------------------------------------------------------- |
| 좌우 스와이프      | ✅   | 첫 장이 가장 최근. **목표(채팅방)당 한 장**             |
| 자동 넘김          | ✅   | 4초마다. 사용자가 직접 넘기면 10초간 멈춤               |
| 카드 종류          | ✅   | 메시지 💌 / 공지 📢 / 광고 🎁. 메시지만 본문 2줄 말줄임 |
| 누르면 채팅방 이동 | ✅   | 메시지는 목록에서 즉시 제거(읽은 것으로 처리)           |
| 빈 상태            | ✅   | "모든 메시지를 확인했어요."                             |
| 자동 갱신          | ✅   | 창 포커스·탭 복귀 시 재조회                             |

### 4.2 오늘의 집중

| 기능           | 상태 | 설명                                               |
| -------------- | ---- | -------------------------------------------------- |
| 오늘 집중 시간 | ✅   | 집중 탭에서 쌓인 값                                |
| 목표 시간      | ✅   | **오늘 텐미닛 플래너의 계획 시간 합계**            |
| 연속 달성일    | ⬜   | 서버 계산 필요(투두가 체크된 날 기준). 현재 임시값 |

### 4.3 집중 시작하기 CTA

| 기능         | 상태 | 설명 |
| ------------ | ---- | ---- |
| 집중 탭 이동 | ✅   |      |

### 4.4 진행 중인 목표

| 기능                    | 상태 | 설명                                                                       |
| ----------------------- | ---- | -------------------------------------------------------------------------- |
| 목표 카드               | 🟡   | 목표 이름 + D-day + 진행률 막대. 진도가 없으면 `○월 ○일부터 진행 중이에요` |
| 세로 목록 · 페이지 넘김 | ✅   | 카드 3장마다 페이지 분할, 아래에 `1 / 2` 표시                              |
| 목표 추가하기           | ✅   | 카드 맨 끝에 하나. 채팅 탭으로 이동해 개설 팝업을 연다                     |
| 진행률                  | 🟡   | `current / total` 백분율. **진도 스키마 미확정**                           |

### 4.5 알림

| 기능           | 상태 | 설명                                                                     |
| -------------- | ---- | ------------------------------------------------------------------------ |
| 안 읽은 표시   | ✅   | 헤더 벨 아이콘 우측 상단 빨간 점                                         |
| 알림 목록      | 🟡   | 말풍선 팝업. **최대 5개**, 넘치면 오래된 것부터 사라짐                   |
| 읽음 처리      | ✅   | **목록을 닫는 순간** 전부 읽음. 안 읽음은 연한 브랜드 톤, 읽음은 흰 배경 |
| 알림 종류      | 🟡   | 독촉 / 투두 추가 / 투두 완료 / 밤 11시 미완료 / 플래너 미작성            |
| 일반 채팅 알림 | —    | **만들지 않는다.** 독촉(nudge)만 알림 대상                               |
| 실시간 수신    | ⬜   | 현재는 진입 시 조회만. 푸시·SSE 미구현                                   |

## 5. 채팅

### 5.1 채팅 목록 `/chat`

| 기능         | 상태 | 설명                                                             |
| ------------ | ---- | ---------------------------------------------------------------- |
| 목표 목록    | 🟡   | 아바타(없으면 이름 첫 글자) + 이름 + 최근 메시지 + 시각          |
| 안 읽음 배지 | ✅   | 99 초과는 `99+`                                                  |
| 정렬         | ✅   | 최근 메시지 최신순. **읽어도 순서가 바뀌지 않는다**              |
| 검색         | ✅   | 방 이름 + 최근 메시지 한 줄. 프론트 필터링                       |
| 목표 개설    | 🟡   | `+` 버튼 → 팝업(채팅방 이름·사진·목표·프롬프트). **이름만 필수** |
| 숨긴 방      | ✅   | 목록에서 제외                                                    |

### 5.2 채팅방 `/chat/:goalId`

| 기능          | 상태 | 설명                                                                                   |
| ------------- | ---- | -------------------------------------------------------------------------------------- |
| 헤더          | ✅   | 뒤로가기 / 채팅방 이름 + 목표 이름 / 모아보기 버튼                                     |
| 말풍선        | ✅   | 내 메시지 브랜드 색(오른쪽), AI 흰색(왼쪽)                                             |
| 시각 표시     | ✅   | 말풍선 바깥 아래(카카오톡 방식). 같은 분에 이어지면 마지막 줄에만                      |
| 발신자 표시   | ✅   | 연속 메시지는 첫 줄에만 이름·아바타                                                    |
| 날짜 구분선   | ✅   | `2026년 8월 3일 월요일` 형식으로 통일                                                  |
| 메시지 전송   | 🟡   | 낙관적 업데이트(먼저 그리고 확정). 실패 시 "다시 시도"                                 |
| 과거 메시지   | ✅   | 위로 스크롤하면 10개씩 이어붙임(커서 페이지네이션) + 스크롤 위치 보정                  |
| 입력창        | ✅   | Enter 전송 / Shift+Enter 줄바꿈, 한글 조합 중 Enter 무시, 최대 120px 자동 확장, 1000자 |
| 파일 첨부     | 🟡   | 클립 버튼 → OS 파일 선택창. **jpg·png·pdf·txt**, 10MB 제한                             |
| 사진 미리보기 | ✅   | 말풍선 안에 썸네일(가로는 말풍선 폭, 세로 최대 288px). 누르면 전체 화면 확대           |
| AI 응답       | 🟡   | 고정 문구 반환. 대기 중 "○○님이 입력 중..."                                            |
| SSE 스트리밍  | ⬜   | 스펙 확정, 구현은 서버 연동 후                                                         |

### 5.3 모아보기 `/chat/:goalId/archive`

| 기능            | 상태 | 설명                                                         |
| --------------- | ---- | ------------------------------------------------------------ |
| 파일 탭         | 🟡   | 연-월(`2026-08`)로 묶어 2열 카드. 확장자별 아이콘 색         |
| 사진 탭         | 🟡   | 연-월로 묶어 정사각 3열. **동영상은 받지 않음**              |
| 진도 탭         | 🟡   | 원형 진도율 + 목표명 + 단계 수 + 점·선 타임라인              |
| 진도 애니메이션 | ✅   | 0%에서 실제 값까지 차오름                                    |
| 완료 목표       | ✅   | 🏆 + 컨페티 + 진행 기간·소요 일수 + 회고 지표 3종            |
| 회고 지표       | ⬜   | 집중 시간·완료한 할 일·가장 열심히 한 달. **서버 집계 필요** |
| 사진 확대 보기  | ✅   | 채팅방과 같은 뷰어 공유                                      |
| 파일·사진 저장  | ⬜   | 웹에서는 갤러리 저장 불가. 앱 전환 후 진행                   |

### 5.4 목표 설정 `/chat/:goalId/settings`

모아보기 헤더의 톱니바퀴로 진입한다.

| 기능             | 상태 | 설명                                                                                    |
| ---------------- | ---- | --------------------------------------------------------------------------------------- |
| 기본 정보 수정   | 🟡   | 사진 / 채팅방 이름(10자) / 목표(50자) / 프롬프트(500자). **변경 시에만 저장 버튼 활성** |
| 기한             | 🟡   | 날짜 선택. 즉시 저장. 홈 카드 D-day에 반영                                              |
| 진도             | ⬜   | 읽기 전용. 스키마 확정 후 편집                                                          |
| 목표별 알림 끄기 | 🟡   | 전역 알림 설정과 별개. 즉시 저장                                                        |
| 목표 완료 처리   | 🟡   | 확인 팝업 → 진도 100% + 완주 기록                                                       |
| 채팅방 숨기기    | 🟡   | 목록에서만 숨김. 히스토리에서 되돌릴 수 있음                                            |
| 대화 내용 삭제   | 🟡   | 메시지만 삭제, 목표·기록은 유지                                                         |
| 목표 삭제        | 🟡   | 확인 팝업. **삭제 시 데이터 처리 정책 미합의**                                          |

## 6. 집중 `/focus`

| 기능             | 상태 | 설명                                                             |
| ---------------- | ---- | ---------------------------------------------------------------- |
| 오늘 집중 요약   | 🟡   | 집중 시간 / 목표 시간 + 진행 막대                                |
| 지금 계획 안내   | 🟡   | 플래너에 잡힌 시간대면 "지금은 ○○ 집중하는 시간이에요"           |
| 방식 전환        | ✅   | 스톱워치 ↔ 뽀모도로                                              |
| 스톱워치         | ✅   | 한 바퀴 60분, 계속 누적. 브랜드 색                               |
| 뽀모도로         | ✅   | 집중 25분(빨강) → 휴식 5분(초록), **4번마다 15분 긴 휴식**       |
| 단계 전환 알림   | ✅   | 알림음 + 토스트 + OS 알림                                        |
| 조작             | ✅   | 시작 / 일시정지 / 이어서 하기 / 종료                             |
| 시간 유지        | ✅   | **시작 시각 기준 계산**이라 탭 이동·백그라운드에도 어긋나지 않음 |
| 세션 저장        | 🟡   | 스톱워치는 종료 시, 뽀모도로는 집중 25분마다                     |
| 목표 달성 축하   | ✅   | 컨페티 + "오늘의 집중 시간 달성!" (하루 한 번)                   |
| 탭 제목 표시     | ✅   | 다른 탭에서도 `24:13 집중 · nudgely`                             |
| 상주 알림        | ⬜   | 웹 불가. Capacitor 래핑 후 네이티브 알림 필요                    |
| 목표별 집중 시간 | ⬜   | 세션에 목표 id를 붙여야 가능                                     |

## 7. 기록 `/record`

캘린더 ↔ 텐미닛 플래너를 세그먼트 탭으로 전환한다(방향에 맞는 슬라이드 애니메이션).

### 7.1 캘린더

| 기능                   | 상태 | 설명                                                                 |
| ---------------------- | ---- | -------------------------------------------------------------------- |
| 월 이동                | ✅   | `< 2026년 8월 >`                                                     |
| 날짜 선택              | ✅   | 선택일은 브랜드 원, 오늘은 연한 브랜드 배경. 일요일 빨강·토요일 파랑 |
| 날짜별 점              | ⬜   | 기록 유무 표시 미구현                                                |
| 오늘 총 집중 시간 카드 | ⬜   |                                                                      |

### 7.2 투두

| 기능          | 상태 | 설명                                                                   |
| ------------- | ---- | ---------------------------------------------------------------------- |
| 날짜별 조회   | 🟡   | **투두는 날짜마다 새로 생성**된다. 캘린더에서 고른 날짜 기준           |
| 카드          | 🟡   | 목표 이름 제목 + 항목 + 진행 수(`2/4`)                                 |
| 체크 표시     | ✅   | 완료 시 브랜드 체크 + 취소선. **AI가 갱신하므로 화면에서는 읽기 전용** |
| 분류 태그     | ✅   | 강의·복습 등                                                           |
| 좌우 슬라이드 | ✅   | 목표별 카드. 5개 이하는 점, 초과는 `n / m`                             |
| 빈 상태       | ✅   | 할 일이 없는 목표는 카드를 그리지 않음                                 |

### 7.3 텐미닛 플래너

| 기능           | 상태 | 설명                                                                                              |
| -------------- | ---- | ------------------------------------------------------------------------------------------------- |
| 날짜 이동      | ✅   | `< 8월 3일 월요일 >`. **오늘 이후로는 이동 불가**                                                 |
| 표             | 🟡   | 1시간 단위, 06:00~24:00(설정에서 변경), 스크롤 없이 한 화면                                       |
| 막대           | ✅   | 가로 길이 = 그 시간에서 차지한 비율. 계획(연한 브랜드) / 실제(집중 세션·학습 인증·직접 기록별 색) |
| 요약           | ✅   | 계획·달성·미달성 블록 수와 달성률. **10분 = 1블록**, 계획 칸에 실제가 겹치면 달성                 |
| 계획 수정      | —    | AI가 정하며 사용자는 바꿀 수 없다                                                                 |
| 실제 기록 수정 | ⬜   | 표시만 가능                                                                                       |

## 10. 공통 규칙

### 10.1 레이아웃

- 모든 화면은 **모바일 폭(448px)** 안에 가운데 정렬된다.
- 채팅방·설정·모아보기 등 하위 화면은 하단 탭바 없이 전체 화면을 쓴다.

### 10.2 데이터 상태

모든 조회 화면은 **로딩(스켈레톤) → 성공 / 실패(다시 시도) / 빈 상태** 네 가지를 갖는다.

### 10.3 저장 방식

| 방식              | 쓰는 곳                                              |
| ----------------- | ---------------------------------------------------- |
| 즉시 저장(낙관적) | 설정 토글, 기한, 알림 끄기 — 실패 시 되돌리고 토스트 |
| 명시적 저장       | 프로필, 목표 기본 정보 — 변경이 있을 때만 버튼 활성  |
| 낙관적 추가       | 채팅 메시지 — 먼저 그리고 실패 시 "다시 시도"        |

### 10.4 알림 표시

| 방식              | 쓰는 곳                                              |
| ----------------- | ---------------------------------------------------- |
| 토스트(상단, 3초) | 화면 전환이 있거나 사용자가 다른 곳을 볼 수 있을 때  |
| 인라인 문구       | 입력값 오류처럼 위치가 분명할 때                     |
| 확인 팝업         | 되돌리기 어려운 동작(로그아웃·탈퇴·삭제·숨기기·완료) |

### 10.5 시간 표기

서버는 ISO 8601 절대 시각만 주고, 프론트가 상황에 맞게 바꾼다(`src/utils/date.ts`).

| 위치        | 형식                                                    |
| ----------- | ------------------------------------------------------- |
| 채팅 목록   | 방금 / 10분 전 / 3시간 전 / 오늘 / 어제 / 요일 / 지난주 |
| 알림        | 방금 / n분 전 / n시간 전 / n일 전                       |
| 말풍선      | 오전 9:00                                               |
| 날짜 구분선 | 2026년 8월 3일 월요일                                   |
| 첨부 묶음   | 2026-08                                                 |

기기 시계를 기준으로 계산하며, 화면을 다시 그릴 때만 갱신된다(자동 갱신 없음).

### 10.6 접근성·모션

- 모든 아이콘 버튼에 `aria-label`, 진행률·스위치에 적절한 role을 준다.
- `prefers-reduced-motion` 설정 시 화면 전환·컨페티 애니메이션을 끈다.
