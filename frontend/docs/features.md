# 기능 명세서

화면별 기능과 동작 규칙. API 스펙은 [`api.md`](./api.md)를 참고한다.

**상태**: ✅ 동작 · 🟡 화면만(mock) · ⬜ 미구현

> 모든 데이터는 mock(`src/mocks/`)이다. 화면은 전부 완성됐고 서버 연동만 남았다.

---

## 1. 서비스 개요

AI가 학습·습관을 **먼저 챙기고 독촉하는** 앱.

**목표(Goal) = 채팅방.** 목표 하나가 AI와 대화하는 방이고, 거기에 투두·플래너·집중 기록·첨부가 매달린다.

| 화면     | 같은 목표를 보여주는 방식 |
| -------- | ------------------------- |
| 채팅     | AI와 대화하는 방          |
| 홈       | 진행 중인 목표 카드       |
| 기록     | 그날의 투두 카드          |
| 모아보기 | 파일·사진·진도            |

이름은 둘이다. `name`은 채팅방 별명(Buddy), `title`은 목표 이름(UI/UX 디자인 강의 완주). 홈·기록 카드 제목과 채팅 부제는 `title`을 공유한다.

## 2. 화면 구조

```
/landing  /signin  /signup  /auth/callback/:provider
─────────────────────────── 하단 탭바
/home   /chat   /focus   /record   /my
─────────────────────────── 전체 화면
/chat/:goalId              채팅방
/chat/:goalId/archive      모아보기
/chat/:goalId/settings     목표 설정
/settings                  앱 설정
/settings/history          히스토리(숨긴 채팅방)
```

## 5. 채팅

### 목록 `/chat`

| 기능         | 상태 | 설명                                                         |
| ------------ | ---- | ------------------------------------------------------------ |
| 목표 목록    | 🟡   | 아바타 + 이름 + 최근 메시지 + 시각                           |
| 안 읽음 배지 | ✅   | 99 초과는 `99+`                                              |
| 정렬         | ✅   | 최근 메시지순. **읽어도 순서가 바뀌지 않는다**               |
| 검색         | ✅   | 이름 + 최근 메시지, 프론트 필터링                            |
| 목표 개설    | 🟡   | `+` → 팝업(이름·사진·AI 성격·목표·프롬프트). **이름만 필수** |
| 숨긴 방      | ✅   | 목록에서 제외                                                |

### 채팅방 `/chat/:goalId`

| 기능           | 상태 | 설명                                                       |
| -------------- | ---- | ---------------------------------------------------------- |
| 헤더           | ✅   | 뒤로가기 / 이름 + 목표 이름 / 모아보기                     |
| 말풍선         | ✅   | 내 메시지 브랜드 색(오른쪽), AI 흰색(왼쪽)                 |
| 시각·발신자    | ✅   | 시각은 말풍선 바깥 아래, 연속 메시지는 첫 줄에만 이름      |
| 날짜 구분선    | ✅   | `2026년 8월 3일 월요일`                                    |
| 메시지 전송    | 🟡   | 낙관적 업데이트, 실패 시 "다시 시도"                       |
| 과거 메시지    | ✅   | 위로 스크롤하면 10개씩 이어붙임 + 스크롤 위치 보정         |
| 입력창         | ✅   | Enter 전송 / Shift+Enter 줄바꿈, 한글 조합 중 무시, 1000자 |
| 파일 첨부      | 🟡   | **jpg·png·pdf·txt**, 10MB                                  |
| 사진 미리보기  | ✅   | 말풍선 썸네일(최대 288px), 누르면 전체 화면 확대           |
| AI 응답        | 🟡   | 고정 문구. 대기 중 "○○님이 입력 중..."                     |
| SSE 스트리밍   | ⬜   | 스펙 확정, 연동 후 구현                                    |
| 파일·사진 저장 | ⬜   | 웹에선 갤러리 저장 불가. 앱 전환 후                        |

### 모아보기 `/chat/:goalId/archive`

| 기능      | 상태 | 설명                                                     |
| --------- | ---- | -------------------------------------------------------- |
| 파일 탭   | 🟡   | 연-월로 묶어 2열 카드, 확장자별 아이콘 색                |
| 사진 탭   | 🟡   | 연-월로 묶어 3열. 누르면 채팅방과 같은 뷰어로 확대       |
| 진도 탭   | 🟡   | 원형 진도율(0→목표값 애니메이션) + 점·선 타임라인        |
| 완료 목표 | ✅   | 🏆 + 컨페티 + 기간·소요일수 + 회고 지표 3종              |
| 회고 지표 | ⬜   | 집중 시간·완료한 할 일·가장 열심히 한 달. 서버 집계 필요 |

### 목표 설정 `/chat/:goalId/settings`

모아보기 헤더의 톱니바퀴로 진입.

| 기능             | 상태 | 설명                                                     |

| 기본 정보 수정   | 🟡   | 사진·이름(10자)·목표(50자)·프롬프트(500자). 변경 시 저장 |

| 진도             | ⬜   | 읽기 전용. 스키마 확정 후 편집                           |
| 목표별 알림 끄기 | 🟡   | 전역 설정과 별개, 즉시 저장                              |
| 목표 완료 처리   | 🟡   | 확인 팝업 → 진도 100% + 완주 기록                        |
| 채팅방 숨기기    | 🟡   | 목록에서만 숨김. 히스토리에서 되돌림                     |
| 대화 내용 삭제   | 🟡   | 메시지만 삭제                                            |
| 목표 삭제        | 🟡   | 확인 팝업. **데이터 처리 정책 미합의**                   |

캘린더 ↔ 텐미닛 플래너를 세그먼트 탭으로 전환(방향 슬라이드 애니메이션).

### 캘린더

| 기능      | 상태 | 설명                                                         |
| --------- | ---- | ------------------------------------------------------------ |
| 월 이동   | ✅   | `< 2026년 8월 >`                                             |
| 날짜 선택 | ✅   | 선택은 브랜드 링 + 확대, 오늘은 회색 원                      |

| 꽃 연출   | ✅   | 피어나는 등장(45ms 간격), 날짜를 누르면 살짝 흔들림          |

| 기능                  | 상태 | 설명                                                 |
| --------------------- | ---- | ---------------------------------------------------- |
| 날짜별 조회           | 🟡   | **투두는 날짜마다 새로 생성**                        |
| 카드                  | 🟡   | 목표 이름 제목 + 항목 + 진행 수(`2/4`) + 분류 태그   |

### 텐미닛 플래너

| 기능           | 상태 | 설명                                                        |
| -------------- | ---- | ----------------------------------------------------------- |
| 날짜 이동      | ✅   | `< 8월 3일 월요일 >`. **오늘 이후 이동 불가**               |
| 표             | 🟡   | 1시간 단위, 06:00~24:00(설정에서 변경), 스크롤 없이 한 화면 |

## 10. 공통 규칙

**레이아웃** — 모든 화면은 모바일 폭(448px) 안에 가운데 정렬. 채팅방·설정·모아보기는 탭바 없이 전체 화면.

**데이터 상태** — 조회 화면은 로딩(스켈레톤) → 성공 / 실패(다시 시도) / 빈 상태를 갖는다.

**저장 방식**

| 방식              | 쓰는 곳                                              |
| ----------------- | ---------------------------------------------------- |
| 즉시 저장(낙관적) | 설정 토글, 기한, 알림 끄기 — 실패 시 되돌리고 토스트 |
| 명시적 저장       | 프로필, 목표 기본 정보 — 변경이 있을 때만 버튼 활성  |
| 낙관적 추가       | 채팅 메시지 — 먼저 그리고 실패 시 "다시 시도"        |

**알림 표시**

| 방식              | 쓰는 곳                                         |
| ----------------- | ----------------------------------------------- |
| 토스트(상단, 3초) | 화면이 바뀌거나 사용자가 다른 곳을 볼 때        |
| 인라인 문구       | 입력값 오류처럼 위치가 분명할 때                |
| 확인 팝업         | 되돌리기 어려운 동작(로그아웃·탈퇴·삭제·숨기기) |

**시간 표기** — 서버는 ISO 8601만 주고 프론트가 변환한다(`src/utils/date.ts`).

| 위치        | 형식                                                    |
| ----------- | ------------------------------------------------------- |
| 채팅 목록   | 방금 / 10분 전 / 3시간 전 / 오늘 / 어제 / 요일 / 지난주 |
| 알림        | 방금 / n분 전 / n시간 전 / n일 전                       |
| 말풍선      | 오전 9:00                                               |
| 날짜 구분선 | 2026년 8월 3일 월요일                                   |
| 첨부 묶음   | 2026-08                                                 |

기기 시계 기준이며 화면을 다시 그릴 때만 갱신된다.

**접근성·모션** — 아이콘 버튼에 `aria-label`, 진행률·스위치에 role 부여. `prefers-reduced-motion` 설정 시 전환·컨페티·꽃 애니메이션을 끈다.

## 11. 남은 작업

**프론트에서 가능**

- 플래너 실제 기록 수정, 투두 직접 체크
- 파일·사진 저장(앱 전환 후가 나음), 약관 링크 연결

**서버 필요**

- API 실제 연동(`src/api/` 8개 파일), SSE 스트리밍
- 연속 달성일, 마이페이지 통계 3종, 목표 회고 지표
- 밤 11시 독촉 알림(스케줄러 + 푸시), 실시간 알림 수신

**앱 전환(Capacitor)**

- 푸시 알림, 집중 중 상주 알림, 알림 권한·기기 토큰 등록, 안전 영역, 안드로이드 뒤로가기

**팀 작업**

- 카카오·구글 클라이언트 ID 발급 (이것만 하면 소셜 로그인 동작)
- Apple 개발자 계정 (스토어 출시 시)

**결정 필요** — 목표 진도 스키마 · 목표 삭제·탈퇴 시 데이터 처리 · 토큰 갱신 정책 · 집중 세션에 목표 id 추가 · 스토어 출시 여부
