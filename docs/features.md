# 기능 명세서

화면별 기능과 동작 규칙. API 스펙은 [`api.md`](./api.md)를 참고한다.

**상태**: ✅ 동작 · 🟡 일부만 동작 · ⬜ 미구현

> **서버 연동이 끝났다.** `src/mocks/` 는 없어졌고 `src/api/` 9개 파일이 전부 실제 백엔드를 호출한다.
> ⬜만 실제로 남은 작업이다.

---

## 1. 서비스 개요

AI가 학습·습관을 **먼저 챙기고 독촉하는** 앱.

**목표(Goal) = 채팅방.** 목표 하나가 AI와 대화하는 방이고, 거기에 투두·플래너·집중 기록·첨부가 매달린다. 홈의 목표 카드, 기록의 투두, 모아보기가 모두 같은 id의 목표를 다른 각도로 보여준다.

이름은 둘이다. `name`은 채팅방 별명(Buddy), `title`은 목표 이름(UI/UX 디자인 강의 완주).

## 2. 화면 구조

```
/landing  /signin  /signup  /auth/callback/:provider
─────────────────────────── 하단 탭바
/home   /chat   /focus   /record   /my
─────────────────────────── 전체 화면
/chat/:goalId              채팅방
/chat/:goalId/archive      모아보기
/chat/:goalId/settings     목표 설정
/settings                  앱 설정
/settings/history          히스토리(숨긴 채팅방)
```

| 기능           | 상태 | 설명                                     |

| 목표 시간      | ✅   | **오늘 플래너의 계획 시간 합계**         |

| 목표 추가하기  | ✅   | 채팅 탭으로 이동해 개설 팝업             |

### 알림

| 기능         | 상태 | 설명                                                     |
| ------------ | ---- | -------------------------------------------------------- |
| 안 읽은 표시 | ✅   | 벨 아이콘에 빨간 점                                      |
| 알림 목록    | ✅   | 말풍선 팝업, **최대 5개**                                |
| 읽음 처리    | ✅   | **목록을 닫는 순간** 전부 읽음                           |
| 알림 종류    | ✅   | 독촉 / 투두 추가 / 완료 / 밤 11시 미완료 / 플래너 미작성 |
| 누르면 이동  | —    | **이동하지 않는다.** 알림은 '무슨 일이 있었는지' 만 알리고, 앱에서는 푸시로 앱이 열리는 것까지가 역할이다 |

| 실시간 수신  | ⬜   | 앱이 열린 동안 밀어주는 수신은 없다. **서버 푸시 채널 필요** |
| 일반 채팅 알림 | —  | **만들지 않는다.** 독촉만 대상                           |

## 5. 채팅

### 목록 `/chat`

| 기능      | 상태 | 설명                                                       |
| --------- | ---- | ---------------------------------------------------------- |
| 목표 목록 | ✅   | 아바타 + 이름 + 최근 메시지 + 시각 + 안 읽음 배지          |
| 정렬·검색 | ✅   | 최근 메시지순(**읽어도 순서 불변**), 검색은 프론트 필터링  |
| 목표 개설 | ✅   | `+` → 팝업(이름·사진·AI 성격·목표·프롬프트). **이름만 필수** |
| 숨긴 방   | ✅   | 목록에서 제외                                              |

### 채팅방 `/chat/:goalId`

| 기능           | 상태 | 설명                                          |
| -------------- | ---- | --------------------------------------------- |
| 말풍선·날짜 구분선 | ✅ | 내 메시지 오른쪽, AI 왼쪽                     |
| 메시지 전송    | ✅   | 낙관적 업데이트, 실패 시 "다시 시도". **재시도는 전송 키로 중복 저장을 막는다** |
| 과거 메시지    | ✅   | 위로 스크롤하면 커서 페이지네이션으로 이어붙임 |
| 입력창         | ✅   | 1000자 제한                                   |
| 파일 첨부      | ✅   | **jpg·png·pdf·txt, 10MB**                     |
| 사진 미리보기  | ✅   | 말풍선 썸네일 → 누르면 전체 화면 + 다운로드 버튼 |
| AI 응답        | ✅   | 실제 모델이 답하고 투두·플래너·진도를 도구로 갱신한다. **첨부(사진·pdf·txt) 내용도 읽는다** |
| SSE 스트리밍   | ✅   | `message_start → delta* → done`. 화면에는 한 번에 띄우고, 길면 **여러 말풍선으로 나눠** 보낸다 |
| 나가도 답 유지 | ✅   | 답이 오는 중에 방을 나가도 생성은 끝까지 돌아 저장된다 |
| 쓰다 만 메시지 | ✅   | 방을 떠났다 와도 입력 중이던 글이 남는다(방별로 보관) |
| 파일·사진 저장 | 🟡   | 다운로드 동작. **갤러리에 직접 저장은 앱 전환 후**   |

### 모아보기 `/chat/:goalId/archive`

| 기능      | 상태 | 설명                                          |
| --------- | ---- | --------------------------------------------- |
| 파일 · 사진 탭 | ✅ | 연-월로 묶어 표시. 사진은 썸네일, 뷰어·다운로드는 원본 |
| 파일 열기·다운로드 | ✅ | 카드를 누르면 새 탭. 브라우저가 못 여는 형식은 자동 다운로드 |
| 사진 다운로드 | 🟡 | 사진을 눌러 확대한 뒤 **아래쪽 다운로드 버튼**. 채팅방 뷰어도 동일 |
| 진도 탭   | ✅   | 진행률은 홈 카드와 같은 값(분량 진도). 마일스톤은 타임라인이며 **진도를 따라 자동 갱신**된다 |
| 완료 목표 | ✅   | 완주 축하 화면 + 기간·소요일수                |
| 회고 지표 | ✅   | 집중 시간·완료한 할 일·가장 열심히 한 달. 집중 시간은 집중 탭에서 목표를 골라야 쌓인다 |

### 목표 설정 `/chat/:goalId/settings`

| 기능             | 상태 | 설명                                             |
| ---------------- | ---- | ------------------------------------------------ |
| 기본 정보 수정   | ✅   | 사진·이름(10자)·목표(50자)·프롬프트(500자)       |
| 기한             | ✅   | 즉시 저장. 홈 D-day에 반영                       |
| 진도             | ✅   | 현재/전체/단위를 직접 고친다. 서버가 0≤current≤total 로 자르고 마일스톤도 따라 갱신 |
| 목표별 알림 끄기 | ✅   | 전역 설정과 별개, 즉시 저장                      |
| 목표 완료 처리   | ✅   | 확인 팝업 → 완주 기록. AI 가 대화 중 처리하면 채팅방에서 바로 축하 |
| 채팅방 숨기기    | ✅   | 목록에서만 숨김. 히스토리에서 되돌림             |
| 대화 삭제 · 목표 삭제 | ✅ | **삭제 시 데이터 처리 정책 미합의**             |
| AI 성격 수정     | ✅   | 설정에서 바꾸거나 '선택 안 함'으로 되돌린다. 즉시 저장 |

## 10. 공통 규칙

**데이터 상태** — 조회 화면은 로딩(스켈레톤) → 성공 / 실패(다시 시도) / 빈 상태를 갖는다.

**저장 방식**

| 방식              | 쓰는 곳                                              |
| ----------------- | ---------------------------------------------------- |
| 즉시 저장(낙관적) | 설정 토글, 기한, 알림 끄기 — 실패 시 되돌리고 토스트 |
| 명시적 저장       | 프로필, 목표 기본 정보 — 변경이 있을 때만 버튼 활성  |
| 낙관적 추가       | 채팅 메시지 — 먼저 그리고 실패 시 "다시 시도"        |

**시간 표기** — 서버는 **ISO 8601(UTC)만** 주고 프론트가 상대 시간·날짜 형식으로 변환한다(`src/utils/date.ts`). 날짜 파라미터는 사용자 로컬 기준 `YYYY-MM-DD`.

## 11. 남은 작업

**프론트에서 가능**

- 약관 링크 연결, 갤러리 직접 저장(앱 전환 후가 나음)

**앞뒤 다 필요**

- 비밀번호 재설정 — 재설정 토큰 발급 + 메일 발송

**서버 필요**

- 독촉(nudge) 자동화 — 규칙 설계 + 스케줄러에서 대상 선정 → 문구 생성 → 발송 (M3)
- **알림 실시간 수신 채널** (지금은 진입·포커스 때 재조회만 한다) (M3)
- 리프레시 토큰 — 만료·갱신 정책 미정 (M3)

**보안 후속**

- `/static` 업로드가 인증 없이 열려 있다. 파일명이 uuid 라 추측은 어렵지만,
  링크가 새면 누구나 받는다. 실서비스 전에 서명 URL 이나 인증 경유 다운로드로.
- 토큰 만료 7일 + 무효화 수단 없음(리프레시 토큰과 함께 정리)

**앱 전환(Capacitor)**

- 푸시 알림, 집중 중 상주 알림, 알림 권한·기기 토큰 등록

**팀 작업**

- 카카오·구글 클라이언트 ID 발급 (이것만 하면 소셜 로그인 동작)

**결정 필요** — [`api.md` 8장](./api.md#8-결정이-필요한-것)
